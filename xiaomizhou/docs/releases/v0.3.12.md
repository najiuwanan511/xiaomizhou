# xiaomizhou v0.3.12

修正淘宝分享文案传参：控制台和单商品群消息使用折淘客时，会保留完整分享文案与淘口令。多商品消息仍逐个提交链接，避免不同商品的口令混用。

折淘客明确返回“商品 ID 解析错误”时，尝试一次 e.tb.cn / m.tb.cn 短链自带的 tk 淘口令；两次调用共用 20 秒预算，保留原 SID、PID、RID。授权失败不重试，不启用付费商品 ID 解析。

解析失败提示给出完整文案重试、折淘客同参数在线测试和授权/商品支持检查步骤，不再把解析错误直接归因于 RID。包含 v0.3.11 的 RID 入口说明修正。

验证：提供商与服务集成测试 24 项通过，覆盖完整文案保留、混合商品隔离、口令回退次数、授权错误不重试和参数保留。确认问题截图中的淘宝短链可返回商品跳转页面；尚未用该用户的真实折淘客授权验证转链成功，自动化模拟测试不代表真实权限或订单归因通过。
