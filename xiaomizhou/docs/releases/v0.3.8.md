# xiaomizhou v0.3.8

淘宝返利新增折淘客接入。在「返利转链 → 淘宝 → 接入方式」选择「折淘客」，填写折淘客 AppKey、淘宝授权 SID、完整 PID；手机 APP 分享内容还需代理类型授权、渠道 PID 和渠道关系 ID（RID）。这些参数须对应自己的已授权淘宝联盟账号。

- 保留淘宝官方直连，独立保存两种接入方式的配置。
- 使用折淘客高佣转链接口，通过固定 HTTPS 地址和 POST 请求转链，支持推广链接、淘口令、商品名、主图和预估佣金返回。
- 后台测试和群消息采用与京东相同的链接提取逻辑，支持淘宝／天猫链接、e.tb.cn 和 m.tb.cn 短链以及含链接的完整 APP 分享文案。没有 URL 的纯口令暂不支持。
- 淘宝结果接入自动回复、群转发、自定义文案和图片开关；支持同一条消息同时包含淘宝和京东链接。
- 配置页补充 SID、完整 PID 和 RID 的区别，提供授权管理和 PID 管理入口；上游授权失败或商品不可推广时显示对应错误。

验证：35 项自动化测试通过，覆盖参数与编码、响应解析、配置切换、错误输入、整段分享文案和淘宝／京东混合消息。外部接口响应在测试中模拟，真实转链和订单归因需使用已授权的折淘客账号确认。
