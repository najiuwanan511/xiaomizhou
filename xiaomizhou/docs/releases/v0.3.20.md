# v0.3.20 · 个人 QQ 掉线与恢复提醒

「个人 QQ」新增「QQ 掉线提醒」配置：支持 PushPlus（微信接收）、企业微信机器人和 SMTP 安全邮件。默认关闭，填写渠道信息、保存并发送测试通知，确认接收后开启。

服务端每 15 秒检测，关闭网页仍可运行。默认持续离线 60 秒后提醒，等待时间可设为 30–3600 秒；首次扫码前不误报，同一次掉线成功通知后不重复发送，可选择恢复通知。NapCat 不可达、鉴权异常和掉线后重新等待扫码均计入持续异常。手动 OneBot 使用真实在线状态判断。

失败按退避间隔自动重试；已通知状态随数据库保存，重启后继续监测。个人 QQ 日志记录通知提交与失败原因，页面展示最近检测、通知和错误状态。通知凭证在接口与日志中隐藏，测试按钮限制为每 30 秒一次。邮件采用校验证书的 SSL/TLS 直连，通常使用 465 端口。

包含 86 项自动化测试，新增通知配置校验、HTTPS 渠道响应检查、模拟 SMTP 交互与中文邮件编码、短暂掉线取消、去重、恢复与失败重试、并发发送保护，以及没有打开页面时的后台检测和重启恢复验证。外部通知均使用模拟传输测试；实际渠道需用户填入自己的凭证并确认收到测试通知。

本地浏览器验证配置页面、渠道切换、中文错误、保存后凭证隐藏和桌面／窄屏布局。发布流水线另行构建完整镜像并检查真实 QQ/NapCat 生成二维码，不登录个人账号。

完整 v0.3.18／v0.3.19 镜像可在小米粥「在线更新」升级至 v0.3.20；运行依赖与更新文件清单保持兼容。完整镜像为 `ghcr.io/najiuwanan511/xiaomizhou:v0.3.20`，NapCat 仍为 4.18.42、Linux QQ 仍为 3.2.34-53644。升级时保留原数据卷。
