# xiaomizhou v0.3.6

京东返利新增折京客（折淘客京东板块）接入。在「返利转链 → 京东」选择接入方式，填写折京客 AppKey 和已授权的京东联盟 ID 即可保存配置，不需要京东 AppSecret。现有京东官方直连仍可使用，两套凭据分开保存。

- 支持基础短链接转链，并接入已有自动回复、群转发和文案模板。
- 可选请求商品详情，使用上游返回的商品名、口令、预估佣金和图片；图片、佣金等数据需要折京客额外审核。
- 使用固定 HTTPS 接口和 POST 请求，显示上游授权错误，日志中的密钥继续脱敏。
- 补充京东短链接和 getResult 响应兼容，避免只返回短链接时被误判为失败。

本次也包含此前本地 v0.3.5 的更改：移除返利测试模式和自定义接口，拼多多改用多多进宝官方转链；按用户要求，控制台 AppSecret 字段直接明文显示。

验证：30 项自动化测试通过；包含配置保存和切换、请求字段、两种响应格式、授权错误及无效链接。HTTPS 接口可达性已用不带凭据的请求验证。实际推广转链与订单归因仍需用户使用自己的已授权账号测试。

升级后进入「返利转链 → 京东 → 折京客」。先完成折京客京东账号授权，保持「请求商品详情」关闭，保存后执行单链接测试。完整步骤见 `docs/affiliate-jd-taobao.md`。
