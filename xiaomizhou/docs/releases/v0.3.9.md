# xiaomizhou v0.3.9

AI 新增唤醒、退出和空闲超时。在「AI 大脑」可配置唤醒前缀、退出命令和 1–120 分钟的空闲时间，默认 5 分钟。

- 发送 `AI` 或 `唤醒AI` 开始，`AI 问题` 可直接提问；唤醒后同一用户可连续对话。
- 发送 `退出AI`、`退出 AI`、`结束对话` 或自定义命令结束。退出仅影响当前用户在当前会话的 AI，不关闭返利和插件。
- 私聊升级后也需先唤醒。个人 QQ 群按群和用户隔离；QQ 官方机器人仍需每条 @。
- 空闲超时静默结束，重新唤醒使用新上下文。等待和控制命令不调用模型。退出后尚未生成完的回答不再发送。
- 保存 AI 配置、清空历史或重启会结束当前会话。退出不删除已有历史记录。
- 保留插件与返利回复优先级，配置修改申请仍需管理员审核。

验证：自动化测试覆盖唤醒、连续对话、退出、超时、用户和群隔离、配置校验、上下文重置及 QQ 消息投递。模型响应使用模拟数据，未调用真实付费接口。
