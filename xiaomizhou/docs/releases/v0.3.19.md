# v0.3.19 · 中文日志与个人 QQ 独立日志

运行日志的级别、模块及常见事件改为中文，已有英文日志查看时同样转换。新增按级别和模块筛选、每 5 秒自动刷新、暂停刷新；长消息编号与错误详情自动换行，适配桌面和窄屏。

「个人 QQ」页新增专属日志，包含 NapCat 的扫码等待、上线、掉线、消息接通、重启、内核更新状态，以及个人 QQ 消息的插件、AI、返利、回复、转发、失败和自动重试。按消息来源隔离，不混入 QQ 官方机器人、企业微信等其他渠道事件；状态不变时不重复刷屏。来源不明的旧插件／返利记录保留在全局日志。

补充消息处理完成、发送目标和发送成功记录；发送失败保留上游错误码及具体原因。日志隐藏已知 QQ 连接凭证、回调令牌和二维码载荷，未知上游技术错误保留原文。

包含 77 项自动化测试，新增历史日志迁移、中文显示、个人 QQ 来源隔离、筛选后截取、登录状态去重、刷新竞态与页面退出清理、发送失败诊断检查。本地浏览器使用模拟数据验证筛选和桌面／窄屏布局；发布流水线另行构建完整镜像并检查真实 QQ/NapCat 生成二维码。没有使用个人账号实际扫码和收发消息。

已使用完整 v0.3.18 镜像的用户，可直接在小米粥「在线更新」升级至 v0.3.19；依赖与更新文件清单保持兼容。也可使用完整镜像 `ghcr.io/najiuwanan511/xiaomizhou:v0.3.19` 更新容器，保留原数据卷。NapCat 内核仍为 4.18.42，配套 Linux QQ 仍为 3.2.34-53644。

飞牛 Intel/AMD x86_64 一键安装／重建（使用同一 Compose 项目与命名卷）：

```bash
curl -fsSL https://raw.githubusercontent.com/najiuwanan511/xiaomizhou/v0.3.19/xiaomizhou/compose.image.yml | sudo docker compose -p xiaomizhou -f - up -d
```

若原先手动创建了其他项目或使用绑定目录，请在原项目中更换镜像标签并保留原挂载，避免创建新的空数据卷。
