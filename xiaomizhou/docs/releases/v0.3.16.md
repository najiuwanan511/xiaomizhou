# xiaomizhou v0.3.16

## 转发关键词拦截与文字／链接替换

- 每条转发规则可配置禁止关键词，命中任意一个就跳过该条。支持忽略英文大小写，并统一全角字符进行关键词比较。
- 原文和处理后的最终文案都检查，避免删除原禁词后绕过拦截，也阻止替换内容引入禁止关键词。
- 添加最多 20 条文字或链接替换，按列表顺序替换全部匹配项，留空表示删除。支持调整顺序；使用字面匹配，不执行正则表达式。
- 普通图片和图文继续按原来的排列发送。跨多个文字段的替换仍保留中间图片位置。
- 合并聊天记录逐条过滤和替换，命中的节点跳过，其余节点继续发送，保留稳定的节点去重标识。
- 在返利转链后执行内容替换，可改商品文案或实际推广链接；空消息、超长消息不会发送，拦截与替换记录写入运行日志。
- 新增无需保存规则的「预览处理结果」，显示允许／禁止、命中的关键词及替换结果。预览不发送消息，不调用联盟或 AI 接口。

## 使用

升级后到「转发规则」编辑规则，在「关键词拦截与内容替换」填写关键词（每行一个），添加原文与替换内容，预览确认后保存。

详细示例：[转发规则教程](https://github.com/najiuwanan511/xiaomizhou/blob/main/xiaomizhou/docs/napcat-forwarding.md)。

## 验证与边界

完整 54 项测试通过，包括数据库迁移、实际服务端发送链路、合并记录逐条拦截、图文顺序、跨文字段替换、返利后的推广链接替换、字面匹配、删除、长度限制、预览鉴权及不发送消息。通过本地浏览器验证添加、上下移动、保存后回显、文字／链接替换预览和关键词拦截。没有使用用户的真实 QQ 账号发送消息。

关键词检查文字，不识别图片中的文字；这些设置作用于配置的自动转发规则，插件自己生成的转发动作不套用该规则配置。旧规则默认不设置关键词或替换项。
