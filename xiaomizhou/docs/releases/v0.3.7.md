# xiaomizhou v0.3.7

修复返利测试框无法识别手机 APP 整段分享文案的问题。现在可以直接粘贴「【京东】商品链接＋口令＋商品标题＋打开提示」，后台会提取商品 URL 再调用已配置的转链接口。

- 测试框改为多行输入，支持商品链接或完整分享文案。
- 保留京东 `3.cn` 短链的 `jkl` 等查询参数，兼容中文引号、括号、换行和网址协议的反斜杠转义。
- 后台测试和群消息自动转链共用链接提取逻辑；转链失败仍拦截相应转发。
- 测试框含多个不同商品链接时明确提示分开测试。没有链接的纯口令暂不支持；群消息仍最多处理前五个已识别商品链接。

验证：32 项自动化测试通过。使用用户提供的京东分享文案验证接口输入提取、折京客请求参数、自动回复、群转发和失败拦截；外部转链响应在测试中模拟，未使用用户密钥发起真实推广请求。

升级至 v0.3.7 后刷新页面，在「返利转链 → 京东 → 链接 / 分享文案测试」直接粘贴整段内容。已有返利配置无需重新填写。
