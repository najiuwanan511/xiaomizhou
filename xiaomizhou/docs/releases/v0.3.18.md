# v0.3.18 · 内置 NapCat 与独立内核更新

新增 QQ/NapCat 完整内核的单镜像打包：用户只安装小米粥，后台扫码后自动接通消息收发。启动器管理 QQ/NapCat 的启动、重启和退出，登录数据持久保存，更新小米粥后端时保留 QQ 进程。

「个人 QQ」新增 NapCat 在线更新：检查稳定版本、下载并校验完整发行包、独立重启内核、启动失败自动回滚、手动恢复上一版。保留数据库、QQ 登录文件、用户插件与转发规则。跨大版本或配套 QQ 环境变化时需升级完整镜像。

默认构建输入已固定为 NapCat 4.18.42 + Linux QQ 3.2.34-53644 归档，包含 SHA-256 校验与构建准备脚本；无需安装用户另找 NapCat。发布流程先检查真实内核生成二维码，再推送镜像。

包含 72 项自动化测试。发布流程在 GitHub Linux Runner 上构建完整镜像，启动实际 QQ/NapCat 并验证生成登录二维码，通过后才推送镜像和创建此 Release。此检查不登录个人账号，真实扫码确认和消息收发仍需在目标设备验证。

飞牛 Intel/AMD x86_64 设备可在 Docker → Compose 中使用镜像 `ghcr.io/najiuwanan511/xiaomizhou:v0.3.18`；具体配置见 [飞牛安装说明](https://github.com/najiuwanan511/xiaomizhou#飞牛-os-安装)。此发布镜像为 linux/amd64，ARM64 需按源码构建说明处理。

新增 qrcode、yauzl 依赖及内核运行环境，首次升级须重建完整镜像。保留数据卷；迁移完整登录状态需备份整个数据目录。

修复首次初始化并发创建多个管理员、退出登录后旧会话仍可使用，以及手动回滚在配置恢复中断时缺少恢复记录的问题，并增加对应回归测试。

NapCat 在线更新源为第三方发行归档。目前官方仓库 Releases 为空，不能直接从官方获取新版，也不保证归档源会持续发布。
