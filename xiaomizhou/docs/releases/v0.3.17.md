# xiaomizhou v0.3.17

## 内置时间命令

- 发送 `time`、`/time`、`时间` 或 `当前时间`，小米粥直接回复系统当前时间、日期和星期，固定显示北京时间（UTC+8）。英文命令不区分大小写，允许首尾空格。
- 系统命令在插件、转发、返利和 AI 处理前识别，无需 AI 密钥或启用 AI，不产生模型请求，也不写入 AI 会话历史。
- 支持 NapCat 个人 QQ 私聊／群聊、QQ 官方机器人私聊／群内 @ 回复，以及已接入的企业微信成员会话。
- 按完整文字命令匹配；带图片、合并聊天记录或其他文字的消息继续走原有处理流程。

## 使用

升级后直接发送 `time`。QQ 官方机器人在群里需要 `@机器人 time`，让开放平台将消息交给机器人。

回复格式：

```text
当前时间：2026-10-06 18:30:00 星期二
北京时间（UTC+8）
```

时间取自运行小米粥的设备系统时钟。

## 验证

55 项测试通过。新增跨日期的时区格式测试，并验证 NapCat 实际发送链路、插件优先级、AI 关闭和已唤醒会话下的系统回复，以及官方机器人私聊和群回复。测试使用模拟平台，没有使用用户 QQ 账号发送真实消息。
