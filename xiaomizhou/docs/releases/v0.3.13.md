# xiaomizhou v0.3.13

修正淘宝 RID 配置说明。实际对照测试已观察到同组参数在 RID 留空时成功、填入 RID 时失败，页面和教程改为：RID 是渠道场景参数，普通转链可先留空验证；渠道归因需匹配的渠道 PID、RID 和授权账号。

收到商品解析错误且配置了 RID 时，提示先对照有无 RID 的结果并检查渠道参数匹配，避免直接归因于授权过期或商品不支持。RID 留空不发送 relation_id；填写时始终保留该参数，失败后不会自动去掉 RID 重试，以免改变归因。

验证：提供商和服务集成测试通过，覆盖 RID 留空时不传参、填写时保留参，以及错误提示。用户提供的真实结果显示留空 RID 可以生成推广链接、淘口令、图片和预估佣金；渠道用户订单归因及实际佣金结算仍需在联盟后台核对。
