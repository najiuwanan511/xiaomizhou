# xiaomizhou v0.3.14

修复 QQ 官方机器人返利转链只收到文字、收不到商品图片的问题。此前发送器没有接收图片参数，始终发送 msg_type=0 的文字消息。

现在 QQ 机器人私聊、群内回复及允许的转发使用官方富媒体流程：先上传商品图片获取 file_info，再以 msg_type=7 发送返利图文。回复保留原 msg_id；多图使用不同 msg_seq，每个动作最多 3 张去重图片。继续受 QQ 平台权限和回复次数等限制约束。

沿用「附带商品图片」开关。接口未返回图片或开关关闭时只发文字。图片上传失败时保留返利文字，在运行日志及 QQ 机器人状态显示平台错误码和原因。首条图文已发送后，后续图片失败记录警告，避免重复发送已成功的内容。图文消息本身失败会报告发送错误。

更新配置页及教程中的图片支持说明，企业微信发送暂维持文字。

验证：完整 Node 测试 47 项通过。新增模拟腾讯平台的群聊/私聊图片协议测试、真实服务端转链到消息发送的集成测试，覆盖图片开关、上传失败时文字回退、错误码显示、序号、去重及凭证隐藏。没有使用用户的 QQ 账号发送真实消息；升级后需用实际机器人核对富媒体权限与腾讯能否读取商品图。
